# Бриф для дизайнера: полный пак иконок VirtDeck

Дата: 2026-10-19.
Задача: полный набор интерфейсных иконок VirtDeck — **48 существующих +
30 новых**, единый визуальный язык, два варианта (light/dark).

Стиль-референс — существующий пак из 48 иконок: сетка 128×128, палитра
семантических градиентов, без фона. Ключевая доработка существующих —
упрощение до читаемости на 24 px (см. требования).

### Не требуется

- `app` — бренд-знак рисуем сами, замене не подлежит.
- `loading` — спиннер анимируется процедурно (поворот дуги), статика не нужна.

## 2. Технические требования

1. **Читаемость на 24 px — первична** (24 px — база иконок во всех темах
   приложения; меньших размеров в UI нет). Текущие иллюстрации рассчитаны
   на крупный размер: при уменьшении 128 → 24 px штрих 2 px превращается
   в 0,4 px, детали сливаются. Нужно: крупный силуэт, без мелких деталей,
   минимум градиентов; на 48 px иконка может оставаться иллюстрацией.
2. **Без SVG-фильтров** (`feDropShadow` и пр.) — рендерер приложения
   поддерживает только Tiny-профиль SVG, фильтры молча выбрасываются.
3. **Свободный правый нижний угол** — поверх иконки рисуется статус-точка
   (~22 % размера иконки).
4. **Два варианта light/dark** для каждой иконки; имя файла = id
   (нижний регистр, дефис).
5. **Единый стиль** — сетка 128, та же палитра градиентов, что у
   существующих 48.
6. **manifest.json** — записи вида (id, label_ru, light, dark).

## 3. Приёмка

- Силуэт каждой иконки различим на 24 px (дерево, тулбар) и на 48 px
  (пустые состояния, диалоги).
- Пары «действие/обратное действие» различимы между собой: start/resume,
  stop/shutdown, reboot/reset, expand/collapse, upload/download,
  export/import.
- Светлый и тёмный варианты читаются на белом и тёмно-сером фоне.
- Статус-точка не теряется на силуэте.
