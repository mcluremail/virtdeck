# Спецификация: какие иконки нужны от SVG-пака

Дата: 2026-10-19.
Контекст: внешний пак `~/virtdeck-svg-icon-pack` (48 иконок × light/dark,
viewBox 128, манифест с русскими метками) примеряется к встроенному набору
`virtdeck/ui/icons.py` (52 имени, viewBox 24, перекраска токенами `ICON_*`).

Как посмотреть пак вживую:

- Каталог сверки: `.venv/bin/python scripts/icon_pack_preview.py` →
  `~/virtdeck-icon-preview.png` — light и graphite (тёмный вариант пака)
  на базе 24 px плюс обе семьи на 48 px, статус-точки.
- Живое приложение: `VIRTDECK_ICON_PACK=~/virtdeck-svg-icon-pack ./run` —
  зампенные имена берутся из пака (вариант следует теме), остальные остаются
  builtin. Без переменной приложение не меняется.

## 2. Чего не хватает — попросить в пак

### P1 — Действия (тулбар ВМ/хоста, палитра команд — самые частые)

| id | Метка | Метафора |
|---|---|---|
| start | Запустить | треугольник play в круге |
| stop | Остановить | квадрат в круге |
| shutdown | Выключить | символ питания (дуга + черта) |
| reboot | Перезагрузить | круговая стрелка + символ питания |
| reset | Жёсткий сброс | круговая стрелка без питания (отличима от reboot) |
| resume | Продолжить | play с чертой (снятая пауза) |
| add | Добавить | плюс |
| remove | Удалить | минус (корзина уже есть в паке — `deleted`) |
| upload | Загрузить | стрелка вверх над основанием |
| download | Скачать | стрелка вниз над основанием |

| collapse | Свернуть | двойной шеврон внутрь |
| clone | Клонировать | два смещённых силуэта машины |
| migrate | Мигрировать | два узла со стрелкой между ними |
| search | Поиск | лупа (глобальный поиск, Ctrl+F) |

### P2 — Железо и устройства (таб Hardware, диски)

| id | Метка | Метафора |
|---|---|---|
| disk | Диск | жёсткий диск (блин с осью) |
| usb | USB | разъём USB / флешка |

### P3 — Доступ (таб Access)

| id | Метка | Метафора |
|---|---|---|
| group | Группа пользователей | несколько фигур, отличимая от `users` |
| role | Роль | бейдж/жетон с фигурой |
| acl | Список доступа | щит с чек-листом |
| lock | Замок | отдельный замок (сейчас натянут на `security`) |
| unlock | Открытый замок | отдельный открытый замок |

`users` в паке — группа фигур: он покрывает и нашего `user`, и `group` сразу;
если автор разведёт одиночную фигуру и группу — маппинг станет точным.

### Не требуется

- `app` — бренд-знак рисуем сами, замене не подлежит.
- `loading` — спиннер анимируется процедурно (поворот дуги), статика не нужна.

## 3. Технические требования к новым иконкам

1. **Читаемость на 24 px — первична** (24 px — база иконок во всех шести
   темах; меньших размеров в UI нет). Текущие иллюстрации пака рассчитаны
   на крупный размер: при 128 → 24 px штрих 2 px превращается в 0,4 px,
   детали сливаются (рендер QSvgRenderer даёт ~220 оттенков-кашу на ячейке
   24 px). Для дерева и тулбара нужна упрощённая версия: крупный силуэт,
   без мелких деталей, минимум градиентов.
2. **Без SVG-фильтров** (`feDropShadow` и пр.) — QtSVG рендерит Tiny-профиль,
   фильтры молча выбрасываются.
3. **Свободный правый нижний угол** — поверх иконки рисуется статус-точка
   (~22 % размера, viewBox-нормированная).
4. **Два варианта light/dark**, как в существующем паке; имя файла = id
   (нижний регистр, дефис).
5. **Стиль** — в языке существующих 48: та же сетка 128, та же палитра.
6. **manifest.json** — дополнить записями (id, label_ru, light, dark).

## 4. Что пак уже даёт сегодня (без работы автора)

Идиомы, которых у нас нет, но пак уже нарисовал — кандидаты на внедрение
под существующие поверхности: `pbs` (узлы PBS сейчас под generic-хранилищем),
`reports` (Fleet Health), `provider`, `tasks`, `notification`,
`warning`/`error`/`success` (статусы), `dashboard`, `help`. На крупных
поверхностях (EmptyState, About, диалоги — 40–64 px) пак применим как есть.

## 5. Приёмка

- Рендер QSvgRenderer на 24/48 px: силуэт различим (каталог
  `scripts/icon_pack_preview.py` перегенерировать — новые id появятся в
  секциях; деревом смотреть через `VIRTDECK_ICON_PACK=...`).
- Каждый маппинг проверять в дереве со статус-точкой (online/offline).
