# Бриф для дизайнера: набор иконок VirtDeck

**Дата:** 2026-09-15 · **Статус:** закрыт — набор принят 2026-09-15
> Итог: владелец утвердил **filled-цветной** набор (v3) с фиксированной
> палитрой: синяя база #3D8BFD/#2563EB, зелёный #22C55E, красный #EF4444,
> оранжевый #F59E0B, фиолетовый #8B5CF6. Иконки Breeze не перекрашиваются
> темами (работают как брендовый `app`). Требования ниже (плейсхолдеры
> `{c}`, монохром) больше не действуют для Breeze-овердрая — сохранены
> как история переговоров с дизайнером.

**Цель:** единый авторский набор из 51 иконки для десктоп-клиента VirtDeck
(управление виртуализацией Proxmox VE, PySide6/Qt).

---

## 1. Контекст

Иконки — inline-SVG, рендерятся `QSvgRenderer` в двух базовых размерах:
**16px** (темы Light/Oxygen/Graphite/System) и **24px** (темы Breeze/Breeze
Dark). Рисунок перекрашивается кодом: дизайнер работает **формой**, цвет
приходит из темы при рендере.

Отрисовка выполняется в диапазоне **12–36px** (см. масштабы в §3), при
этом большинство иконок живёт в 16px (дерево, вкладки, кнопки) —
**читаемость в 16px обязательна**, 12px — желательна.

## 2. Технические требования (критично)

- **viewBox 24×24** (рекомендация; текущий набор — 24, старый — 16).
- Плейсхолдеры цвета в SVG (подставляются при рендере):
  - `{c}` — основной штрих/заливка (цвет текста темы);
  - `{c2}` — приглушённый акцент (второй план);
  - `{ok}` — статусный зелёный (только если глифу нужна статус-точка).
- **Монохром + максимум один приглушённый акцент.** Без градиентов,
  без тени, без заливок фона.
- Единый стиль штриха: толщина ~1.8 на сетке 24, скруглённые концы
  (`stroke-linecap="round"`, `stroke-linejoin="round"`). Fill-элементы —
  только как точки/акценты.
- Тёмная и светлая темы: иконка рисуется один раз, цвет подставляется
  извне — **не закладывать контраст на конкретный фон**.
- `app` — исключение: брендовый знак, фиксированные цвета, темами не
  перекрашивается (см. `virtdeck/ui/brand_assets/`).
- **Статусные точки** (running/stopped у ВМ) рисуются поверх иконки
  деревом отдельно — в глифы их **не включать**.
- Доставка: SVG-файлы (один глиф = один файл, имя = id из §4) — вставим
  в код сами.

## 3. Масштабы (некоторые иконки рендерятся меньше/крупнее базы)

| Масштаб | Имена | Итоговый размер (база 16 / 24) |
|---|---|---|
| 1.5 | app | 24 / 36 |
| 0.875 | refresh, upload, download, export, import, about, lock, unlock, migrate, clone, search | 14 / 21 |
| 0.75 | expand, collapse, add, remove | 12 / 18 |
| 1.0 | все остальные | 16 / 24 |

Для мелких (0.75/0.875) — максимально простая форма, никаких мелких
деталей.

## 4. Список иконок

### 4.1. Объекты дерева (главные персонажи, читаемость критична)

| id | Значение | Где используется | Подсказка по метафоре |
|---|---|---|---|
| `cluster` | Кластер PVE | дерево | связанные ноды / общая шина |
| `host` | Хост (нода PVE) | дерево, контекст-меню | сервер/шасси |
| `vm` | Виртуальная машина | дерево, диалоги | монитор с терминалом |
| `template` | Шаблон ВМ | дерево | vm + признак шаблона (штрих/пунктир) |
| `storage` | Хранилище | дерево, вкладки хоста | дисковая батарея/стек дисков |
| `pool` | Пул ресурсов PVE | дерево | контейнер, объединяющий ВМ |
| `folder` | Группа (папка) в дереве | дерево | папка |
| `ha` | HA-ресурс (high availability) | дерево, контекст-меню | щит / heartbeat |
| `group` | Группы пользователей | вкладка хоста (Permissions) | два силуэта |
| `pbs`-объекты — см. `backup` | PBS-серверы в дереве используют `backup` | дерево | — |

### 4.2. Действия над ВМ/CT (power-набор — должен читаться мгновенно)

| id | Значение | Где | Подсказка |
|---|---|---|---|
| `start` | Запустить | дерево, кнопки деталей, PBS-джобы | ▶ |
| `shutdown` | Корректное выключение | дерево, кнопки | ⏻ (мягкое) |
| `stop` | Жёсткая остановка | дерево, кнопки | ■ |
| `reboot` | Перезагрузка | дерево, кнопки | ↻ |
| `reset` | Жёсткий сброс | дерево, кнопки | ↻+резкость/двойной |
| `resume` | Снять с паузы | дерево, кнопки | ▶ + пауза-черта |
| `pause` (резерв) | Пауза | — | ‖ |

`start`/`stop`/`reboot`/`shutdown` — **визуальная семья**, должны
различаться без чтения подписи. `stop` (жёсткий) и `shutdown` (мягкий)
не должны путаться.

## 5. Приёмка (чек-лист по каждому глифу)

1. Читается в **16px** на светлом и тёмном фоне.
2. Читается в **12px** (масштаб 0.75).
3. Монохром-тест: без `{c2}` глиф остаётся осмысленным.
4. Силуэтный тест: иконка угадывается контуром без деталей.
5. Power-семья (`start/shutdown/stop/reboot/reset/resume`) различима
   «с одного взгляда».
6. Единая оптическая плотность штриха по всему набору.
7. Не содержит зашитых цветов (только `{c}`/`{c2}`/`{ok}`; `app` —
   исключение).

## 6. Референсы

- **Текущий breeze-набор** (50 глифов, KDE-стиль): `virtdeck/plugins/_themes.py` → `BREEZE_ICONS` — отправная точка по составу.
- **Текущий встроенный набор** (угловатый «терминальный» стиль, 16px): `virtdeck/ui/icons.py`.
- Стиль-ориентиры: KDE Breeze, Lucide, Phosphor (тонкий контурный стиль).

## 7. Что просим

1. Единый набор в одном стиле (взгляните на оба текущих — обычно
   предлагается среднее: контурность Breeze + чёткость встроенного).
2. Обязательный минимум: §4.1 (объекты дерева) + §4.2 (power-набор).
3. Приоритет 2: §4.3–4.5. Резервные (`history`, `monitor`, `pause`) —
   по желанию.
4. Светлая и тёмная темы проверяются на нашей стороне — от вас только
   форма.
