мутации, отмена). Существующее покрытие устойчивости широкое (Fleet partial-семантика,
поколения/эпохи, poll-бюджеты, ambiguous-таймауты backup-job CRUD — всё закреплено).
Пробелы:

**PVE:**
1. 429 — ни одного теста (классификация и обработка).
2. Реальные транспортные SSL-ошибки (есть только классификация по тексту и hint 596).
3. 5xx на POST/PUT/DELETE через harness — не воспроизводится (записи тестируются на 400 и таймауте).
4. Не-JSON/пустое тело на обычных GET (harness всегда отдаёт валидный конверт; покрыт только upload-путь).
5. Системные тесты «null вместо списка» для списочных источников (точечные: next_vmid, roles, poll).
6. D1–D3, D5–D9, D13–D15 — сценарии не закреплены (см. таблицу в §3).
7. Прокси-отказ (407/недоступен) — только конфигурационные тесты.

**PBS:**
1. 429/404/5xx на HTTP-уровне — нет (ветка 404 в `FakePbsApi` мертва).
2. Transport Timeout/ConnectionError в `_request` (GET/POST/DELETE) — покрыт только login-путь.
3. Неопределённый исход мутаций (таймаут после отправки) — не покрыт вовсе; re-login на 401 для POST/DELETE — только чтение ветки.
4. Отмена/поколения PBS-воркеров — механизма и тестов нет (только tag-mismatch).
5. Login 200 без тикета; не-JSON при логине (D11); структура ответов (dict вместо списка).
6. D10, D16 — не закреплены.

**Классификация (D4):** отсутствует тест «requests-исключение с URL, содержащей 401/403/404».

## 6. Уже корректно обработанные сценарии

- **Трёхзначная семантика задач:** `TaskAPI.poll` — stopped/OK, timeout («клиент сдался,
  задача жива»), poll_failed («исход неизвестен», бюджет 3 транспортных сбоев, auth —
  сразу) (`provider/_tasks.py:46-97`); `_await_task` доносит все три до UI санитизированно
  (`backend/core.py:68-97`). Тесты: poll-бюджеты, `test_timeout_is_not_a_failure_claim` и др.
- **Мутации без автоповторов:** таймаут записи никогда не ретраится автоматически
  (`provider/_cluster.py:248-251`); единственный повтор — VMID-конфликт ПОСЛЕ
  подтверждённого отказа (`core.py:116-132`, дублирование исключено); PBS re-login один раз
  при 401 — запрос был отвергнут до исполнения (`pbs/client.py:119-123`).
- **Backup jobs CRUD:** путь выбирается до записи (probe `/cluster/jobs` кэшируется,
  404/501 → легаси; иные ошибки не маскируются); таймаут → «outcome unknown»
  (`_cluster.py:141-260`) — закреплено тестами.
- **Частичные сборы:** FetchWorker — error/partial/optional-None (`fetch.py:469-491`);
  кэш не отравляется error-строками (`config.py:776-795`), сохранение только после
  успешного apply; UI сохраняет предыдущие данные при неудаче (пакет
  `test_refresh_lifecycle`). Fleet Health: ошибка источника ≠ пусто, «unverified» ≠
  «Never backed up» (этапы 6.1.x–6.2.x).
- **Защита от запоздалых ответов:** три слоя — эпохи `RefreshCoordinator`
  (`refresh.py:156-171`), гейты `panel._generation` / `current_obj_id` / `_tasks_gen`,
  conn_id-гейты. Закреплено тестами (`test_stale_generation_…`, `test_conn_gates`).
- **Отмена/закрытие:** `FetchWorker.cancel` — 7 точек, ни одного эмита; выход приложения —
  cancel → `clear()` → `waitForDone(1000)`; все эмиты под RuntimeError-guard;
  `provider.close()` в `finally` на всех путях всех воркеров (проверено построчно).
- **Гигиена секретов:** токены/пароли не попадают в URL и журналы (upload — заголовок,
  login PBS — тело POST, `tokens.py:176/188` — `password=None`; `_sanitize_error`
  вычищает URL/host; логируются только метод/статус).
- **Разбор ответов:** upload-путь полностью защищён (не-JSON, не-dict, AnyEvent 595–599,
  кап 500 символов); `from_exception` — status_code атрибут побеждает текст
  (`test_status_code_wins_over_message_text`); PBS `_request` толерантен к не-JSON
  (→ None, а не крэш); домен PBS устойчив к мусору (`test_from_api_bad_time`).
- **Параллельность PBS:** свежий `PbsProvider` на прогон воркера, закрытие в `finally`
  (`pbs/workers.py:43-60`) — разделяемого между потоками клиента нет; `fleet/pbs_source.py`
  закрывает провайдер даже при сбое.
- **`ui/api/fleet.py`:** честный sprawl-скан — per-VM сбои в `failed`, кластер-сбой →
  «unavailable», свежий список гостей с фолбэком.
- **WsBridge/EventBus:** гонка stop-before-loop закрыта флагом (`bridge.py:50-60`);
  EventBus изолирует падение хендлера.
