# Аудит UI — 2026-10-08 (полный проход, мажор v3.0)

Полный проход `virtdeck/ui/**` — мажорный релиз (исключение из
дельта-правила, см. [AUDIT_PROCESS.md](AUDIT_PROCESS.md)). UX-потоки не
менялись: только вместимость контента, скроллы и интервалы.

## Метод

1. Статический скан: все `setFixed*` / `setMaximum*` / `setMinimum*` /
   `setSpacing` / `setContentsMargins` по `virtdeck/ui/**` (60+ точек).
2. Поведенческий харнесс `tests/ui/test_locale_fit.py`: 16 диалогов +
   виджет задач кластера × 6 локалей (en/ru/ar/zh/fr/es) — сверка
   `sizeHint` каждого дочернего виджета с его maximum-ограничениями.
   Локальный i18n подменяет только переводы; `seed_translations`
   замокан (тесты не пишут в реальный config.sqlite).
3. RTL-проверка (ar): направленные CSS-свойства в QSS.

## 🔴 Исправлено (с регрессиями)

1. **Клип текстовых кнопок в локалях** — 60 точек в 13 файлах:
   `setFixedWidth(120/100/80)` на кнопках Ok/Cancel/Up/Down/Yes/No →
   `setMinimumWidth`. В fr «Descendre»/«Enregistrer» не влезали в 80/120px
   и обрезались. Стрелки boot-order (40px, символы «>»/«<») и
   `vmid_line` (числа) оставлены фиксированными.
2. **`setFixedSize` на диалоге удаления ВМ** (mainwindow) →
   `setMinimumWidth(480)`: перенесённый предупреждительный текст + до двух
   чекбоксов не влезали в фиксированные 240/280px высоты в локалях,
   скролл невозможен по определению.
3. **`setFixedSize(420, 130)` на `_confirm_delete`** →
   `setMinimumWidth(420)` + `setWordWrap(True)` у сообщения: длинные
   подтверждения обрезались одной строкой; интервалы приведены к стилю
   остальных диалогов (margins 20, spacing 12).
4. **Фильтр-бар задач кластера**: `setMaximumWidth(90)` у комбостата
   статусов → 140 (ru «Выполняется» клипался), `setFixedHeight(30)` снят
   (высота по контенту), margins 4/3 → 8/6, spacing 4 → 6.
5. **StorageConfigDialog**: общая форма + типоспецифичные поля (у rbd/ceph
   длинные формы) обёрнуты в `QScrollArea` (widgetResizable, без рамки);
   кнопки остаются снаружи скролла и всегда видимы. Раньше форма росла без
   ограничения, а при низкой высоте окна нижние поля были недостижимы.
6. **Интервалы**: PBS-вкладки — межблочный отступ 4px → 8px (×3);
   role_dialog — список привилегий spacing 4 → 6.
7. **CardList**: колонки фиксированной ширины клипали длинные значения
   (имена хостов/ВМ) без доступа к тексту — добавлен tooltip с полным
   значением для title/field-лейблов.

Регрессия: `test_locale_fit.py` ловит любую future-`setFixedWidth` на
виджете, чей translated sizeHint шире (и `setMaximum*` вообще), во всех 6
локалях; тест i18n-паритета включён туда же.

## ✅ Проверено чисто

- create_vm_dialog, role_dialog — скроллы уже были; detail_panel — все
  плотные вкладки в скроллах, QTableWidget живут от прокси-стиля 24px.
- Дерево, тулбар, command palette — `setIconSize(base_size())` явно.
- fleet_health, search_dialog — autofit колонок.
- `vmid_line` 120px (числовое), стрелки 40px, спиннер/бренд/toggle —
  без локализуемого текста.
- Комбостаты языков/тем 110px — переводы влезают (теперь minimum).
- RTL (арабская локаль): направленных CSS-свойств в QSS нет (только
  симметричные нули и некритичный padding спиннера); раскладки
  зеркалятся Qt автоматически.
- i18n: паритет ключей 1278 ×5 локалей (тест).
- Минимальные ширины диалогов 350–500px: Qt не даёт ужать окно ниже
  layout-minimum, поэтому подписи форм клипаться не могут.

## 🟡 Наблюдения (не чинить молча)

1. QSS комбостатов: `QComboBox::drop-down { width: 16px }` — слот стрелки
   остался 16px при базовом размере иконок 24px. Косметика, заметно только
   при внимательном рассмотрении.
2. CardList: ширины колонок задаются вызывающим кодом (summary-вкладки
   хоста). Заголовки-переводы сейчас влезают, но при добавлении новых
   колонок/локалей легко промахнуться — харнесс не покрывает CardList с
   заполненными данными (нужны фейковые данные колонок).
3. `QLabel` в card_list не эллипсирует (обрезает по глифу). Tooltip
   смягчает, но каноничнее elide через QFontMetrics — отдельная задача,
   если понадобится.
